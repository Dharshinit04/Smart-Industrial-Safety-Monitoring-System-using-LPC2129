# Smart-Industrial-Safety-Monitoring-System-using-LPC2129

##  Project Overview
The Smart Industrial Safety Monitoring System is an embedded systems project developed using the LPC2129 ARM7 microcontroller. It monitors industrial parameters using sensors and detects unsafe conditions to improve workplace safety.

##  Features
- Real-time industrial parameter monitoring.
- Sensor interfacing with LPC2129.
- Threshold-based hazard detection.
- LCD display for monitoring system status.
- LED and buzzer alerts for unsafe conditions.

##  Technologies & Tools
- **Microcontroller:** LPC2129 (ARM7)
- **Programming Language:** Embedded C
- **IDE:** Keil µVision
- **Hardware:** Sensors, LCD, LEDs, Buzzer

##  Working Principle
1. Sensors collect industrial parameter readings.
2. LPC2129 processes the sensor data.
3. Readings are compared with predefined safety limits.
4. If an unsafe condition is detected, alerts are activated.
5. The system continuously monitors the environment.

##  Applications
- Industrial safety monitoring.
- Factory automation.
- Hazard detection.
- Manufacturing environments.
